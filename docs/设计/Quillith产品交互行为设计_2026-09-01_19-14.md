# Quillith 产品交互行为设计

## 1. 运行模式

- Interactive：`Quillith [options]`
- Exec：`Quillith exec [options] <instruction>`

## 2. 公共启动配置

- `--memory=on|off`
- `--permission=ask|bypass`

## 3. Interactive Runtime Commands

- `/memory [state|on|off]`
- `/permission [state|ask|bypass]`
- `/exit`

## 4. 状态语义

- CLI 参数：启动时设置 `AgentState`。
- Slash Command：运行中修改 `AgentState`。

## 5. 默认值

- Memory：ON
- Permission：
  - Interactive：ASK
  - Exec：BYPASS

## 6. 输入分类

- `/` 开头：CLI 控制命令
- 其他文本：Agent Prompt
